# المنيو الإلكتروني (Restaurant QR Menu)

تطبيق منيو إلكتروني كامل مبني بـ Next.js 14 + TypeScript + Tailwind CSS + Prisma/PostgreSQL، يحتوي على:

- **صفحة المنيو للزبون** (`/`): تصفح الأصناف حسب التصنيف، صورة + وصف + سعر لكل طبق، شارة "عرض خاص" عند وجود خصم، تقييمات الزبائن، وزر لإرسال شكوى/اقتراح.
- **لوحة تحكم الإدارة** (`/admin`): إدارة الأصناف والأسعار مع حاسبة تلقائية للكلفة ونسبة الربح وفرق السعر (بنفس منطق ملف الإكسل)، رفع الصور، إدارة التقييمات (الموافقة/الحذف)، وإدارة الشكاوى (تغيير الحالة/الحذف).

## منطق حساب الأسعار (يطابق ملف الإكسل)

```
إجمالي الكلفة = كلفة المنتج + كلفة السلطة
نسبة الربح % = (السعر - إجمالي الكلفة) / إجمالي الكلفة × 100
فرق السعر = السعر الجديد - السعر القديم
```

هذا المنطق مطبّق في `src/lib/pricing.ts` ويُستخدم مباشرة في لوحة التحكم أثناء إضافة/تعديل أي صنف.

## التقنيات

- Next.js 14 (App Router) + TypeScript
- Tailwind CSS (تصميم عربي RTL بالكامل)
- Prisma ORM + PostgreSQL
- مصادقة إدارية بسيطة (JWT في كوكي httpOnly عبر `jose` + `bcryptjs`)
- الصور تُخزَّن داخل قاعدة البيانات كـ Base64 (وليس على القرص) لتفادي فقدانها بعد كل عملية نشر جديدة على استضافات مثل Railway ذات التخزين المؤقت (ephemeral filesystem) — وهذا كان أحد أسباب فشل النسخة السابقة.

## الإعداد المحلي

```bash
npm install
cp .env.example .env   # ثم عدّل DATABASE_URL و AUTH_SECRET
npm run db:push        # ينشئ الجداول في قاعدة البيانات
npm run db:seed        # يعبئ التصنيفات والأصناف من ملف الإكسل + ينشئ حساب الأدمن
npm run dev
```

- المنيو: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin/login (استخدم `ADMIN_USERNAME` / `ADMIN_PASSWORD` من ملف `.env`)

## النشر على Railway (خطوة بخطوة)

1. أنشئ مشروعاً جديداً على Railway واربطه بهذا المستودع (فرع `claude/restaurant-menu-pricing-svidpc` أو الفرع الرئيسي بعد الدمج).
2. أضف قاعدة بيانات: **New → Database → PostgreSQL**. سيوفر Railway متغيّر `DATABASE_URL` تلقائياً.
3. في إعدادات خدمة التطبيق (Variables)، أضف:
   - `DATABASE_URL` → اربطه بمرجع قاعدة البيانات: `${{Postgres.DATABASE_URL}}`
   - `AUTH_SECRET` → قيمة عشوائية طويلة (`openssl rand -base64 32`)
   - `ADMIN_USERNAME` و `ADMIN_PASSWORD` → بيانات دخول لوحة التحكم
4. Railway سيكتشف المشروع تلقائياً كتطبيق Node عبر Nixpacks وينفذ `npm run build` (سطر `postinstall` يشغّل `prisma generate` أيضاً).
5. بعد أول نشر ناجح، شغّل مرة واحدة فقط (من تبويب **Shell** في الخدمة، أو من جهازك محلياً بتوجيه `DATABASE_URL` لقاعدة بيانات Railway):
   ```bash
   npm run db:push
   npm run db:seed
   ```
   هذا ينشئ الجداول ويعبئ البيانات وحساب الأدمن. **لا داعي لتكراره** في كل عملية نشر لاحقة إلا عند تغيير `schema.prisma`.
6. افتح رابط التطبيق من Railway، ثم `/admin/login` لتسجيل الدخول للوحة التحكم.

### أسباب شائعة لفشل النشر (وكيف تم تفاديها هنا)

| المشكلة الشائعة | الحل المطبّق في هذا المشروع |
|---|---|
| فقدان الصور المرفوعة بعد كل نشر جديد (تخزين مؤقت) | الصور تُخزَّن كـ Base64 داخل قاعدة البيانات نفسها، وليس في `public/uploads` |
| فشل `prisma generate` بسبب اختلاف نظام التشغيل بين البناء والتشغيل | تحديد `binaryTargets` صراحة في `schema.prisma` (`debian-openssl-3.0.x` و `1.1.x`) |
| التطبيق لا يستمع على المنفذ الصحيح | أمر التشغيل `next start -p ${PORT:-3000}` يقرأ متغيّر `PORT` الذي يوفره Railway |
| تشغيل المايكريشن أثناء البناء بدون اتصال بقاعدة البيانات | فُصل تهيئة القاعدة (`db:push` + `db:seed`) عن أمري البناء والتشغيل، وتُنفَّذ يدوياً مرة واحدة بعد أول نشر |
| نسيان متغيرات البيئة (`DATABASE_URL`, `AUTH_SECRET`) | ملف `.env.example` يوثّق كل المتغيرات المطلوبة، والتطبيق يعرض رسالة عربية واضحة بدل الانهيار إذا تعذر الاتصال بقاعدة البيانات |

## هيكل المشروع

```
prisma/schema.prisma       نموذج البيانات (تصنيفات، أصناف، تقييمات، شكاوى، حساب الأدمن)
prisma/seed.ts             تعبئة البيانات الأولية من ملف الإكسل
src/lib/pricing.ts         منطق حساب الكلفة والنسبة وفرق السعر
src/lib/auth.ts            توليد/التحقق من جلسة الأدمن (JWT)
middleware.ts              حماية مسارات /admin و /api/admin
src/app/                   صفحات المنيو ولوحة التحكم (App Router)
src/app/api/               نقاط API العامة والخاصة بالأدمن
src/components/            مكونات واجهة الزبون
src/components/admin/      مكونات لوحة التحكم (نموذج الصنف، حاسبة الأسعار)
```

## أفكار للتوسّع لاحقاً

- إضافة QR Code يولّد رابط المنيو مباشرة (يمكن إضافته كصفحة `/admin/qr` تستخدم مكتبة توليد QR من جهة العميل).
- دعم لغات متعددة (عربي/إنجليزي) عبر `next-intl`.
- إشعارات فورية للإدارة عند وصول شكوى جديدة (بريد إلكتروني أو Telegram Bot).
